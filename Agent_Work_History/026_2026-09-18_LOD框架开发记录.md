# LOD 框架开发记录

## 日期
2026-09-18

## 目标
解决远处高模全精度渲染的性能问题。背景：Furina 300 万索引全精度渲染，拉远后转动视野**卡帧**——需要按距离降档（LOD）。

## 方案
对齐 UE5 传统 Static Mesh LOD：**离线多档模型 + 按距离选档**（不是运行时简化——边坍缩不现实，运行时只做距离判断 + 换模型，零开销）。

## 实现

### 1. PBRModelComponent 扩展（Components.h）
```cpp
struct PBRModelComponent
{
    Ref<PBRModel> Model;                              // LOD0
    std::vector<std::string> LODPaths;                // LOD1/LOD2 路径（json）
    std::vector<float> LODDistances;                  // 切换距离
    std::vector<Ref<PBRModel>> LODModels;             // 运行时 LOD 档
};
```

### 2. 场景 json 格式
```json
"PBRModelComponent": {
    "FilePath": "assets/model/Furina.fbx",
    "LODs": [
        { "Path": "assets/model/Furina_LOD1.fbx", "Distance": 30.0 },
        { "Path": "assets/model/Furina_LOD2.fbx", "Distance": 60.0 }
    ]
}
```

### 3. 序列化/反序列化（SceneSerializer.cpp）
- Serialize：写 LODs 数组（Path + Distance）
- Deserialize：读 LODs → PendingModel（含 LODPaths/LODDistances）→ 异步加载

### 4. 异步加载
- 主模型 + LOD 档都走 `AsyncAssetLoader::LoadModelAsync`（缓存 + 路径归一化已有）
- LOD 档回调按 index 填充 `LODModels[i]`（组件先 AddComponent，再填 LOD）

### 5. 选档逻辑（EditorLayer）
```cpp
Ref<PBRModel> model = pbr.Model;   // LOD0
float dist = glm::length(ctx.Camera.Position - center);
for (size_t i = 0; i < pbr.LODModels.size(); ++i)
    if (pbr.LODModels[i] && dist > pbr.LODDistances[i])
    {
        model = pbr.LODModels[i];
        lodLevel = i + 1;
    }
proxy.Model = model;
```
- 渲染自动兼容：不同档 = 不同 VAO → BatchBuilder 自动分 batch
- 遮挡剔除/视锥剔除用 LOD0 的 AABB（最大，保守）
- 阴影 pass 同档模型（LOD 省阴影三角形）

## 踩坑（重要）

1. **nlohmann type_error**：json LODs 元素缺 `Distance` 字段 → `lod["Distance"].get<float>()` 对不存在的键（operator[] 建 null）抛 type_error。
   **修复**：`lod.value("Distance", FLT_MAX)`（缺省永不切档，防崩溃）
2. **AddComponent(model) vs AddComponent(comp)**：用 `model` 重新构造组件会丢 LOD 数据 + LODModels 未 resize → 回调越界。
   **修复**：用填好的 `comp`（含 LODPaths/Distances + LODModels.resize）
3. **pendingModels.push_back 缺字段**：聚合初始化只给 2 字段 → LOD 数据静默丢失（编译过但逻辑错）。
   **教训**：聚合结构加字段后，所有初始化点都要检查
4. **lodLevel 调试值错**：`else lodLevel = i+1`（没切换才更新，语义反了）→ 调试显示错。
   **修复**：只在切换时 `lodLevel = i + 1`

## Blender 降面导出经验（踩坑）

用 Blender Decimate（简化修改器）生成 LOD 档：

1. **文件变大**：导出时**没勾选"仅导出选中项"** → 导出带了全部 3 份模型。修复：导出面板勾选"仅导出选中项"（Limit to Selected）
2. **位置偏移**：不同 LOD 档模型在空间中位置不一致 → 相机变化时模型跳位置。
   **根因**：LOD 版 FBX 的根节点变换和原模不一致 → 引擎 mesh NodeTransform 不同 → 世界位置漂移。
   **修复（Blender）**：Ctrl+A 应用全部变换 + 模型归位原点（0,0,0）+ 导出勾选"应用变换"（Apply Transform）
3. **判断 LOD 效果看面数**（Blender 右上角统计），不是文件大小（FBX 格式膨胀与几何无关）
4. **导出用 OBJ** 更干净（几何 + UV，无 FBX 多余通道），Assimp 支持
