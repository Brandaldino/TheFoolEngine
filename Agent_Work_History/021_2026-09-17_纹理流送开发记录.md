# 纹理流送开发记录（阶段 1：Mip + LOD Bias）

## 日期
2026-09-17

## 目标
纹理流送第一阶段：为贴图生成 mip 链（消除纹理混叠）+ 距离驱动的 LOD bias（远处强制低 mip，省采样带宽）。真流送（只加载需要的 mip 省显存）留后续。

## 背景
当前引擎纹理无 mip（`glTextureStorage2D` 只分配 1 级，MIN_FILTER=GL_LINEAR），远处纹理混叠闪烁。另发现几何边缘"波浪形" = 阴影摩尔纹（阴影分辨率问题，非本次范围）。

## 一、1a：Mip 生成（已完成）

`OpenGLTexture2D(w,h)` 无 format 构造（贴图路径）：
```cpp
int levels = (int)std::floor(std::log2(std::max(width, height))) + 1;
glTextureStorage2D(m_RendererID, levels, m_InternalFormat, m_Width, m_Height);  // 完整 mip
glTextureParameteri(m_RendererID, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR); // 三线性
```

`SetData` 上传后：
```cpp
glTextureSubImage2D(...);
glGenerateTextureMipmap(m_RendererID);   // 生成 mip 链
```

- 只给贴图（`Create(w,h)` 无 format / `Create(path)`）加 mip；RenderTarget（`Create(w,h,format/Attachment)`）保持 1 级
- 验证：远处纹理稳定平均化，无摩尔纹（mip 正确工作）

## 二、1b：LOD Bias（已完成）

`PBRShader.glsl` main 里按距离算 bias：
```glsl
float distToCam = distance(v_FragPos, u_CameraPos);
float lodBias = min(0.0, log2(distToCam / 10.0));   // 10m 内 bias=0，远处变负（低 mip）
```

贴图采样加 bias 第三参数：
```glsl
vec3 albedo = texture(u_Textures[1], v_TexCoord, lodBias).rgb;
```
（阴影采样不 bias——PCF 不能；prefilter 已用 textureLod）

- 验证：近处贴图不变，远处更早模糊（省采样带宽）

## 三、顺带修复：相机 pitch 奇点翻转

**现象**：拉远相机 + 大俯仰角（pitch 逼近 ±90°），小幅度转视角画面反转几帧又恢复。

**根因**：`RecalculateForward` 的 `m_Right = cross(m_Forward, (0,1,0))` 在 forward 接近竖直时接近零向量 → normalize 未定义 → 画面翻转。且 controller 的 clamp 在 `SetPitch` **之后**（未限制的 pitch 先用于 lookAt，clamp 结果未回写相机）。

**修复**：`PerspectiveCamera::SetPitch` 内部 clamp（防御所有入口）：
```cpp
void PerspectiveCamera::SetPitch(float pitch)
{
    m_Pitch = glm::clamp(pitch, -89.0f, 89.0f);
    RecalculateForward();
}
```

## 四、坑记录

1. **levels 算了没用**：`glTextureStorage2D` 仍传 `1`，`glGenerateTextureMipmap` 对 1 级 storage 无效 → mip 没生成。**修复**：levels 用上。
2. **lodBias 算了没用**：采样 `texture(u_Textures[i], uv)` 没加 bias 第三参数。**修复**：采样加 `lodBias`。
3. **clamp 顺序错**：controller 里 clamp 在 `SetPitch` 之后，未限制 pitch 先用 + clamp 未回写。**修复**：`SetPitch` 内部 clamp。
