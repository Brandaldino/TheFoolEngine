# CSM（级联阴影）尝试与回退记录

## 日期
2026-09-18

## 目标
用 CSM（Cascaded Shadow Maps）解决方向光阴影的远处摩尔纹（1024 单层覆盖全场景，远处 texel 放大成条纹）。

## 背景
- 单层方向光阴影（1024）远处摩尔纹（之前 ground 上观察到）
- PCF（泊松盘）软化近处边缘有效，但远处摩尔纹是分辨率问题，PCF 管不了
- CSM：近处小范围高清 + 远处大范围覆盖，是根治方向

## 尝试过程（分步）

### Step 1：级联矩阵（ShadowMath）✅
- `CascadeSplit`（等比+线性混合，UE5 split scheme）→ splits 17.2 / 38.35 / 100 合理
- `ComputeDirLightCascadeVP`：相机视锥切片 → 光空间 AABB → ortho

### Step 2：数据流（EditorLayer）✅
- 第一个 CastShadow 方向光 3 层级联，其他单层
- `context.CascadeSplits` 传递

### Step 3：ShadowPass 渲染 ✅
- 遍历 ShadowViewProjections 自动渲染 3 层（layers: 3）

### Step 4：splits 传递 ✅
- `u_CascadeSplits` 上传 shader

### Step 5：shader 级联选择 ✅（视觉异常）
- Direction 按距离选级联，采样对应层/矩阵
- **ground 出现不该出现的阴影 + 随相机视角移动**

### Step 6：级联 AABB 修正（多次尝试）
- 修复 ortho near/far（`minB.z-10, maxB.z+10` 替代固定 near=0）→ 奇怪阴影消失
- **但方向光阴影消失**
- 排查：关 Frustum 剔除（无效）、强制 cascade=0（无效）、隔离旧单层（**阴影恢复** → 问题在级联矩阵）
- 打印 AABB/Furina NDC：**模型不在级联 ortho 深度范围**（光空间 z 超界，被 near 裁剪）
- 尝试 padding 100（阴影出现但糊）、级联 AABB 并入场景模型包围盒（阴影仍未出现 + vector out of range）

## 回退决定

**放弃 CSM，回退到 7d697c0（MSAA 稳定点）**。

原因：
1. **架构不适配**：方向光共享单个 DepthArray + shadowIndex 遍历分配，CSM（每光多层 + 级联选择）需大改数据流，反复出 bug
2. **场景太小**：几个模型，远处摩尔纹不明显，CSM 收益低
3. **投入产出比低**：两轮尝试（矩阵/AABB/剔除/splits/深度/模型合并），每次新问题

## 关键教训

1. **CSM 核心难点 = 级联 AABB 必须包含"投射阴影的模型"**，不只相机切片
   - 相机切片在光空间的深度范围有限，斜射时模型光空间 z 超出 ortho near/far → 被裁剪 → 阴影缺失
   - 需并入场景模型包围盒（或按级联距离筛选模型）
2. **padding 治标不治本**：padding 大 → ortho 大 → texel 稀疏 → 糊；padding 小 → 模型在 AABB 外 → 空
3. **一次性做太多**：矩阵/数据流/shader/splits 全一起，多个 bug 交织难排查
4. **调试日志刷屏**：AABB/splits/Furina NDC/layers 每帧打印，干扰排查

## 未来时机（再做 CSM 的正确前提）

1. **阴影系统独立**：每方向光独立阴影资源（非共享 DepthArray），shadowIndex 管理清晰
2. **场景规模上来**：远距离阴影需求明显（大世界）
3. **先做低成本阴影质量改进**：
   - 方向光阴影 1024→2048（近处更清晰，一行）
   - PCF 泊松盘（近处边缘柔和）
   - 点光/聚光 farPlane 调整

## 当前状态

- 回退到 7d697c0（MSAA + 纹理 mip + 阴影预算/分辨率）
- CSM 未提交改动已回退
- 阴影当前：单层 1024 + 3×3 PCF（近处可用，远处摩尔纹留待 CSM 时机成熟）
