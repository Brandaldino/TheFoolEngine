# MSAA 边缘抗锯齿开发记录

## 日期
2026-09-17

## 目标
解决物体边缘几何锯齿（"边缘波浪形"蠕动）：主渲染目标（HDR）开 4x MSAA，渲染时超采样边缘，resolve 后边缘平滑。

## 背景
- 几何边缘锯齿（几何混叠）≠ 纹理混叠：模型轮廓边缘像素覆盖不完整 → 锯齿 + 移动时蠕动
- 之前修过纹理 mip（021 日志），那是纹理内部混叠；边缘需要 AA
- 选 **MSAA**（质量根治）而非 FXAA（略糊）

## 设计：MSAA 封装在 FrameBuffer 内部（外部无感）

```
MainPass → HDR_MSAA(4x renderbuffer) → UnBind 时 blit resolve → 普通纹理
                                                        ↓
Bloom 等后处理读普通纹理（GetColorAttachment 返回 resolved）→ 完全无感
```

### 关键点
- `TextureDesc.Samples`（已有字段）→ `FrameBufferSpecification.Samples` → OpenGLFrameBuffer
- MSAA 用 **renderbuffer**（color + depth24_stencil8），渲染进 multisample
- 额外创建 **resolve 目标**（普通 `Texture2D`）+ resolve FBO
- `UnBind()` 时 `glBlitFramebuffer`（MSAA → 普通）
- `GetColorAttachment()` 返回**普通 resolved 纹理** → 后处理/Bloom 不用改

## 实施

1. `RenderGraph::CreateRenderTarget`：`spec.Samples = desc.Samples`
2. `OpenGLFrameBuffer::Invalidate`：`Samples > 1` 时
   - `glRenderbufferStorageMultisample`（color + depth）
   - resolve 目标（普通纹理）+ resolve FBO
3. `UnBind()`：Samples > 1 → `ResolveMultisample()`（glBlitFramebuffer）
4. `EditorLayer`：HDR 的 `desc.Samples = 4`（其余目标 1）

## 验证

- 物体边缘锯齿消失，边缘平滑（拉近拉远稳定）
- 后处理（Bloom/ToneMapping）正常（读 resolved 普通纹理）
- 显存 +4x（仅 HDR 目标，可接受）

## 坑 / 注意

- resolve 时机必须在渲染完、后处理读之前 → `UnBind` 里做最自然
- 深度必须也 multisample（否则边缘深度不抗锯齿，会出现边缘深度测试问题）
- 阴影图（DepthOnly）不需要 MSAA（Samples=1）
- Resize 时 Invalidate 重建（含 MSAA renderbuffer + resolve FBO）
