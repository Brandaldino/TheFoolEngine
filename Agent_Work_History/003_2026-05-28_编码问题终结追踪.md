## 核心发现

通过 hex dump 确认：

```
e8 b4 b4 = 图
e5 9b be = 片
5c       = \
e8 8b b9 = 苹
e6 9e 9c = 果
...
```

**FBX 内部存的纹理路径是合法 UTF-8**，`aiString` 输出的字节完全没有编码损坏。乱码是控制台 UTF-8 字节被按 GBK 渲染产生的假象。

但拼接后路径 `assets/model/FBX/apple/图片/苹果_Bake1_PBR StoA_Diffuse.png`（FBX 路径含 `图片/` 子目录）与实际文件磁盘位置不匹配，导致 `ifstream` 打开失败。
