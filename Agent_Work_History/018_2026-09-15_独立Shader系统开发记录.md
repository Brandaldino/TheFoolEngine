# 独立 Shader 系统开发记录

## 日期
2026-09-15

## 目标
将 shader 从"各 pass 直接 Shader::Create"解耦为**独立 Shader 系统**：统一单例管理、按路径缓存去重、跨模块共享，对齐 UE5 ShaderSystem 的方向（编译产物缓存 + 后续变体/反射/热重载）。

## 现状

- `Shader` 抽象基类 + `OpenGLShader`（OpenGL 实现）：ReadFile → PreProcess（`#type` 解析）→ Compile → uniform 缓存
- **`ShaderLibrary` 已存在但未使用**：Add/Load/Get/Exists 实现完整，但 pass/渲染器全走 `Shader::Create(filepath)` 直接编译
- 问题：
  1. **无缓存去重**：同一文件多处 `Shader::Create` → 重复编译（如 PBRShader 被 MainPass/PBRRenderer 各自创建）
  2. **无单例**：ShaderLibrary 是实例类，无处持有
  3. **无统一生命周期**：shader 归属 pass，职责混杂

## 设计（本次）

### 1. ShaderLibrary 单例化（ShaderSystem 雏形）
```cpp
class ShaderLibrary {
public:
    static ShaderLibrary& Get();          // 单例
    Ref<Shader> Load(const std::string& filepath);   // 去重：存在则返回缓存
    Ref<Shader> Get(const std::string& name);
    bool Exists(const std::string& name) const;
private:
    std::unordered_map<std::string, Ref<Shader>> m_Shaders;
};
```

### 2. Load 去重
```cpp
Ref<Shader> Load(const std::string& filepath)
{
    auto name = /* 从 filepath 提取（OpenGLShader 已做：取文件名）*/;
    if (Exists(name))
        return m_Shaders[name];       // 命中缓存，不重复编译
    auto shader = Shader::Create(filepath);
    Add(name, shader);
    return shader;
}
```

### 3. 迁移调用点
- `EditorLayer`：`Shader::Create(...)` → `ShaderLibrary::Get().Load(...)`（OnAttach 一次）
- `PBRRenderer::Init`：同上
- `IBLUtils`：同上
- pass 持有 `Ref<Shader>` 不变（从 Library 拿到的引用）

## 对齐 UE5

- **本次**：编译产物缓存（同一 shader 文件全局一份）、单例管理、跨模块共享 —— 对应 UE5 `FShaderMapResource`（shader 资源缓存）
- **后续**：
  - 变体管理（`#define` 排列组合，如阴影/无阴影变体）——UE5 `FShaderPermutation`
  - uniform 反射（自动发现 uniform 而非手动 Set）
  - 热重载（文件变更重编译）
  - 异步编译（加载线程）

## 实现顺序

1. ShaderLibrary 单例 + Load 去重
2. 迁移 EditorLayer / PBRRenderer / IBLUtils / Renderer2D 的 `Shader::Create` → `ShaderLibrary::Get().Load`
3. 编译验证（渲染正常、无重复编译日志）
4. 后续：变体/反射/热重载（评估工作量）

## 着色器预编译（本次延伸目标）

### 问题
GPU 编译 shader 很慢（单个几百 ms 到秒级），运行时首次遇到某 shader 才编译 → 卡顿。游戏首次启动播放"Compiling Shaders"画面把所有 shader 编译缓存。

### 方案（当前引擎落地：启动时全量预编译）
1. ShaderLibrary 缓存就绪后，**启动阶段集中 Load 所有 shader 路径**
2. 收集 shader 清单（当前引擎全部 glsl）：
   ```
   PBRShader / SkyBoxShader / DepthOnlyShader / PointShadowDepthShader /
   ToneMapping / BloomExtract / GaussianBlur / BloomCombine / FlatColor /
   Texture / IrradianceConvolution / PrefilterConvolution / BRDFLUT
   ```
3. OnAttach 渲染前逐 Load（编译进缓存）→ 运行时零编译卡顿
4. 可选：启动画面 + 进度显示（后续）

### UE5 参考
- **SCW（ShaderCompileWorker）**：独立进程编译，不阻塞游戏线程
- **FShaderMap**：材质所有变体集合整体编译
- **打包时已编译**：正式版 Cook 阶段编译好，运行时不编译
- **PSO 预缓存**（DX12/Vulkan）：运行时卡顿主要来自 PSO 创建，`PrecachePSOs` 提前创建
