# CSM 优化记录（padding / 级联过渡 / texel snap）

## 日期
2026-10-08

## 背景
CSM 完成后（032），进一步精致化阴影质量。三步优化，每步可编译验证。

## Step 1：padding 优化（近处清晰度 ×2）

**问题**：padding 20（x/y/z 全加）→ 级联 0 x 范围 = 切片 23m + padding 40m = **63m** → 2048/63 ≈ **32 texel/m**（浪费）。
**修复**：x/y padding = 5（texel 边界余量），z 保持 20（容纳模型深度）→ 级联 0 x ≈ 33m → **62 texel/m（翻倍）** → 近处阴影清晰度翻倍。
**教训**：**padding 是"边界余量"，不是"覆盖扩展"**——x/y 只需几 texel 防边缘裁切，太大纯浪费分辨率。

## Step 2：级联过渡（cascade blend，消除边界断层）

**问题**：级联按距离硬切换 → split（17.2/38.35）边界阴影**突然变化**（断层）。
**实现**：split ± 1.5m 过渡区 `smoothstep` 混合相邻级联阴影：
```glsl
float t = smoothstep(prevSplit - cascadeBlend, prevSplit + cascadeBlend, dist);
shadow = mix(shadowPrev, shadow, t);   // 值混合（各自层采样）
```

**踩坑（P0）**：
- **新旧阴影块并存** → 方向光阴影**双重相乘**（`*= (1-shadow)` 两次）
- **新块在 `if(ShadowIndex>=0)` 外** → 非阴影光（ShadowIndex=-1）执行 → `u_ShadowMatrices[-1]` **越界 UB**
**修复**：重组为单一 `if(ShadowIndex>=0) { 点光分支 / 方向光级联分支 }`。

## Step 3：texel snap（消除相机移动抖动）

**问题**：级联 ortho 基于相机位置 → 相机移动 → 级联 AABB 每帧变 → **阴影 texel 网格漂移 → 边缘抖动**。
**实现**：级联 ortho 中心对齐整数 texel：
```cpp
float texelWorld = extent.x / shadowMapSize;
center.x = floor(center.x / texelWorld + 0.5f) * texelWorld;
center.y = floor(center.y / texelWorld + 0.5f) * texelWorld;
minB = center - extent * 0.5f;   // extent 不变 → 覆盖不变
```
**效果**：相机移动时级联按 texel 整数步进 → texel 固定世界网格 → 阴影稳定。

## Step 4（暂缓）：sceneAABB 按级联筛选

**陷阱**：**不能简单排除接收者（Ground）**——MainPass 渲染 Ground 采样时，光空间 z 若超出 ortho → `z>1` → 阴影被跳过 → **丢失阴影**（previous pitfall）。
**收益评估**：当前深度精度（101m/24bit ≈ 6e-6）**不是瓶颈**——Step 4 收益边际小，且准确实现需"级联切片∩模型"求交。**暂缓**。

## 经验总结

1. **padding 是余量不是扩展**（x/y 小，z 大）
2. **级联过渡 = 值混合**（各层阴影值混合，非坐标），过渡区 `smoothstep`
3. **texel snap = 中心对齐整数 texel**（保留 extent）
4. **shader 结构重组时警惕**：新旧阴影块并存 → 双重相乘；缺 ShadowIndex 保护 → 越界
5. **接收者必须留在 ortho 深度内**（否则采样 z>1 丢阴影）
