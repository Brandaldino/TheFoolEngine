## 已完成

### 1. PBRMaterialData.h — 数据结构层
```
PBRVertexData
  ├── position, texCoord (vec2)
  ├── tangent, bitTangent, normal
  └── boneIDs, weights

PBRMeshData
  ├── vertices[], indices[]
  └── MaterialIndex → 指向 Textures[]

PBRMaterialTextureSet
  ├── AlbedoMap, NormalMap, MetallicRoughnessMap, AOMap
  ├── AlbedoFactor, MetallicFactor, RoughnessFactor, AOStrength

PBRMaterialData
  ├── Meshes[]
  └── Textures[]（共享材质池）
```

### 2. ModelLoader.h — Assimp 完全隔离
- 仅暴露 `AssimpImporter::Import(path) → PBRMaterialData`
- 零 Assimp 类型在头文件中
- `PBRMaterial`、`MaterialBuilder`、`MaterialManager` 为骨架声明（待填充）

### 3. ModelLoader.cpp — 完整导入管线
所有 Assimp 类型隐藏在 `static` 自由函数中：
- `LoadTexture` — 支持 embedded (`*索引`) 和 external (文件路径) 纹理加载
- `ProcessMesh` — aiMesh → PBRMeshData (顶点/法线/UV/Tangent/Bitangent)
- `ProcessNode` — 递归遍历节点树
- `ProcessMaterial` — 读 DIFFUSE / BASE_COLOR / NORMALS / UNKNOWN(打包纹理)
- `Import` — 编排器，输出 PBRMaterialData

### 4. 重要发现
- **glTF 的 metallic/roughness/occlusion** 打包在 aiTextureType_UNKNOWN 的一张纹理的 B/G/R 通道，不是旧版的 SPECULAR/SHININESS/AMBIENT
- 旧 `ProcessMaterialTextures` 从 3 张独立贴图各读 .r 是 OBJ 思路，与 glTF 不兼容
