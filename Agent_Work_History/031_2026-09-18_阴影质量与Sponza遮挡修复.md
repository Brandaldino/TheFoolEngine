# 阴影质量改进 + Sponza 遮挡剔除修复

## 日期
2026-09-18

## 一、阴影质量改进

### 目标
解决方向光阴影的远处摩尔纹 + 近处边缘锯齿。

### 1. 分辨率 1024 → 2048
`ShadowTypes.h`：`DIR_SPOT_SHADOW_SIZE = 2048`
- texel 密度 ×4，远处摩尔纹明显减少
- 代价：阴影像素 ×4（Furina 高模阴影开销）——实测 FPS 可接受

### 2. PCF 3×3 固定网格 → 泊松盘 16 采样
`PBRShader.glsl`：`CalculateShadow` 从 3×3 网格改为泊松盘（16 个 2D 偏移，半径 ~1）：
```glsl
vec2 poissonDisk[16] = vec2[](...);   // 16 个偏移

float shadow = 0.0;
float bias = 0.005;
vec2 texelSize = 1.0 / vec2(textureSize(u_ShadowMaps, 0).xy);
for (int i = 0; i < 16; ++i)
{
    float pcfDepth = texture(u_ShadowMaps,
        vec3(projCoords.xy + poissonDisk[i] * texelSize * 2.0, layer)).r;
    shadow += currentDepth - bias > pcfDepth ? 1.0 : 0.0;
}
return shadow / 16.0;
```

### 参数调优记录
| 参数 | 值 | 作用 |
|------|-----|------|
| 偏移半径 `* 2.0` | 2 texel | 边缘柔和度（越大越软）|
| `bias` | 0.005 | 自阴影（acne）/漏光（peter panning）|
| 采样数 | 16 | 质量 vs 性能 |

**泊松盘 vs 固定网格**：无网格感（固定 3×3 有规则锯齿感），更自然的柔和边缘。

### 顺带
- 加 `if (projCoords.z > 1.0) return 0.0`（阴影图外不算阴影，防御）
- 点光阴影已用泊松盘（20 采样）✓

## 二、Sponza 遮挡剔除修复

### 问题
sponza.glb 通过 import model 加载后**不可见**，其他模型正常。

### 根因
**相机在 Sponza 的包围盒（AABB）内部**——遮挡查询时：
- 包围盒前表面在相机前方（大厅远处）
- MainPass 深度 = 相机看到的 Sponza 内部几何（更近）
- 包围盒深度测试全失败 → 查询 0 → 误判遮挡 → 不可见

这是遮挡剔除的**经典边界情况**（Ground 是"扁平贴合"，Sponza 是"相机在包围盒内"）。

### 修复：相机在包围盒内 → 强制可见
```cpp
bool cameraInside =
    glm::abs(ctx.Camera.Position.x - center.x) <= halfExt.x &&
    glm::abs(ctx.Camera.Position.y - center.y) <= halfExt.y &&
    glm::abs(ctx.Camera.Position.z - center.z) <= halfExt.z;

if (!cameraInside && !m_Occlusion->IsVisible(id))
    continue;
```
（标准做法：相机在包围盒内 → 物体必可见，不做遮挡查询。UE5 同理。）

### 验证
- Sponza 正常显示（相机在其中）
- 转视角无消失/闪烁
- 墙挡 Furina 仍正确剔除（遮挡功能不受影响）
- 3 次比较/实体/帧，性能可忽略

## 经验总结

遮挡剔除的**两个边界情况**（都要处理）：
1. **扁平/贴合物体**（Ground）→ 包围盒深度 ≈ 场景深度 → Polygon Offset 解决
2. **相机在包围盒内**（大场景 Sponza）→ 包围盒深度测试失败 → 强制可见
