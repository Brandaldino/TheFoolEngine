## 三、关键技术决策

### 多 Pass 管线设计
后处理链完全在 GPU 端通过 FBO 切换完成：
```
Pass 1: 场景 → HDR FBO（RGBA16F，高精度）
Pass 2: HDR → Bloom 提取 → Bloom FBO_A
Pass 3: Bloom FBO_A → 水平模糊 → Bloom FBO_B
Pass 4: Bloom FBO_B → 垂直模糊 → Bloom FBO_A
Pass 5: HDR + Bloom → 合成 → ToneMapping → LDR FBO（RGBA8）
```

每个 Pass 是独立的全屏四边形 + 独立 shader，任意组合。

### IBL 生成
使用和 Equirect→Cubemap 相同的 FBO + 6 面渲染模式：
- Irradiance Convolution：Riemann 半球积分
- Prefilter：GGX 重要性采样，5 mip 级别
- BRDF LUT：全屏四边形 + 蒙特卡洛积分 → RG16F 纹理

### 渲染抽象分层
| 层级 | 跨 API | 举例 |
|------|--------|------|
| RenderCommand | 是 | `SetDepthFunc` / `DrawArrays` / `Clear` |
| RenderUtil | 否（平台级） | `RenderToCubemapFaces` / `SaveViewport` |
| Resource（Texture/CubeMap） | 是 | 抽象基类 + OpenGL 实现 |
