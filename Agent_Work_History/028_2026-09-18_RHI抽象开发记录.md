## 实现

### 1. StorageBuffer 抽象（SSBO + UBO 通用）
```cpp
class StorageBuffer
{
    virtual void UpLoadData(uint32_t offset, uint32_t size, const void* data) = 0;
    virtual void BindRange(uint32_t binding, uint32_t offset, uint32_t size) = 0;
    static Ref<StorageBuffer> Create(uint32_t size);
};
// OpenGLStorageBuffer : StorageBuffer（Platform/OpenGL）
```
- InstanceRenderer（SSBO）、MainPass UBO、LightPacker 共用

### 2. OcclusionQuery 抽象
```cpp
class OcclusionQuery
{
    virtual void Begin()/End()/Available()/GetResult() = 0;
    static Ref<OcclusionQuery> Create();
};
// OpenGLOcclusionQuery : OcclusionQuery（Platform/OpenGL）
```

### 3. RendererAPI 补齐
```cpp
virtual void SetColorMask(bool r, bool g, bool b, bool a) = 0;
virtual void BindTextureUnit(uint32_t unit, uint32_t textureID) = 0;   // DSA
virtual void BindUniformBuffer(uint32_t binding, uint32_t bufferID) = 0;  // glBindBufferBase
virtual void SetPolygonOffset(bool enable, float factor, float units) = 0;
```

### 4. 收编
- MainPass：UBO → `StorageBuffer` + `BindUniformBuffer`；点光阴影 → `BindTextureUnit`
- LightPacker：`SetGPULightFBO(Ref<StorageBuffer>, ...)` + `UploadData`
- OcclusionPass：`SetColorMask` + `SetPolygonOffset`

## 踩坑（重要）

1. **抽象类实例化（多次）**：
   - `CreateRef<StorageBuffer>(size)` → 应 `StorageBuffer::Create(size)`（工厂）
   - `OcclusionQuery::Create()` 返回 `CreateRef<OcclusionQuery>()` → 应 `CreateRef<OpenGLOcclusionQuery>()`
   - `CreateScope<OcclusionQuery>()`（OcclusionManager）→ 应 `Ref<OcclusionQuery> Query = OcclusionQuery::Create()`
   **教训**：抽象基类的工厂方法（static Create）返回具体实现，调用方绝不能用 `CreateRef<抽象类>`

2. **RendererAPI 加纯虚函数 → 所有实现必须跟上**：加 SetColorMask/BindTextureUnit/BindUniformBuffer/SetPolygonOffset 后，OpenGLRendererAPI 没实现 → "无法实例化抽象类"。
   **教训**：接口扩展 = 实现契约，必须同步

3. **glEnable/glDisable 笔误**：`SetPolygonOffset` 的 else 分支写了 `glEnable`（应 `glDisable`）→ GL_POLYGON_OFFSET_FILL 永远开启 → MainPass 每帧带深度偏移（视觉不明显但状态泄漏）。
   **教训**：状态开关的对称操作（enable/disable）写完后要自查
