## 核心问题：FBX 纹理渲染为白色

用户报告 FBX 模型几何正确，但颜色始终显示为代码中设置的默认白色。

### 控制台日志

```
type=1  path=兀닷쎗\?방옖_Bake1_PBR StoA_Diffuse.png
type=6  path=兀닷쎗\?방옖_Bake1_PBR StoA_Normal.png
type=7  path=兀닷쎗\?방옖_Bake1_PBR StoA_Roughness.png
type=15 path=兀닷쎗\?방옖_Bake1_PBR StoA_Metalness.png
scene embedded texture count: 0
Assertion Failed: Failed to load image.
```

FBX 中的中文贴图路径被 Assimp 错误解码为乱码（mojibake），`?` 标志编码转换失败。

### Pipeline 全线故障链路

1. **Assimp 编码** — Windows ANSI 读取 UTF-8 中文路径 → 乱码
2. **`ModelImporter::LoadTextureFromPath`** — 乱码路径拼接，`std::filesystem::path` 构造无效路径
3. **`m_Directory` 路径分隔符** — `find_last_of('/')` 在 Windows `\` 路径下失效
4. **`OpenGLTexture2D(path)` 构造** — `stbi_load` 失败 → `data=nullptr` → Debug 下 `TF_CORE_ASSERT` 中止，Release 下继续用未初始化数据执行（`internalFormat=0`，`width/height` 为垃圾值）
5. **`LoadTextureFromPath` 不检查加载结果** — 破损坏纹理仍被 `AddTexture` 注册到材质
6. **`MeshRenderer::SetMaterial`** — 检查 `size()!=0` 为 true，用破损纹理而非 `WhiteTexture` 回退
7. **Shader 采样破损纹理** — GPU 采样不完整纹理得到白色/黑色

### `MeshVertexData` 缺少顶点颜色

`MeshData.h:19-27` 结构体无 `Color` 字段，`ProcessMesh` 也未读取 `mesh->mColors[0]`，FBX 顶点颜色信息完全丢失。

## 本次修复：`OpenGLTexture2D` 构造函数容错

文件：`OpenGLTexture.cpp:26-85`

处理方案：
- `stbi_load` 失败 → `TF_CORE_ERROR` 日志 + 回落为 1x1 白色（0xFFFFFFFF 像素）
- `channels` 既非 3 也非 4 → 默认 `GL_RGBA8`/`GL_RGBA`
- `m_Data = nullptr`（原代码存野指针，`stbi_image_free` 后 `m_Data` 指向已释放内存）
- 栈上 `whitePixel` 不释放，只有 stbi 堆分配的数据才调 `stbi_image_free`
