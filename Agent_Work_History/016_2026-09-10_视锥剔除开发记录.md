# 视锥剔除开发记录

## 日期
2026-09-10

## 目标
为编辑器加入视锥体剔除（Frustum Culling）：相机视锥外的实体跳过渲染，降低 draw call，作为渲染性能优化的第一个里程碑。

## 背景
场景保存/加载已完成（015 日志）。渲染目前是**全量提交**（所有 PBRModel 实体每帧都进 RenderContext 渲染，无剔除）。视锥剔除是性能优化第一环，为后续"draw call 下降 → 合批 → 多线程"的优化线打基础。

## 一、已知 Bug 记录（待处理，本次不修）

### Bug A：阴影被正方形边界约束（大模型阴影不完整）
- **现象**：模型过大时，ground 上的阴影呈现在一个正方形区域内，明显不完整
- **猜测**：阴影 framebuffer（DepthArray）分辨率固定（1024×1024）且方向光用 `ortho` 投影（`ortho` 参数固定 10.0），模型超出阴影视锥范围 → 阴影被裁剪
- **方向**：阴影近平面裁剪 / 正交投影范围自适应 / 更大的阴影图。需确认是 ortho 范围还是 shadowmap 分辨率
- **状态**：暂缓，记录待查

### Bug B：运行时切换天空盒，模型不反射新天空盒
- **现象**：编辑器运行时 Import 新天空盒（`SetSkybox`），skybox 背景更新了，但**模型的 IBL 反射（prefilter 镜面反射）仍是旧天空盒**
- **原因分析**：`SetSkybox` 只更新 `Environment.Skybox`，但 `IrradianceMap`/`PrefilterMap` 是启动时由 `IBLUtils::CreateIrradianceMap/CreatePrefilteredMap` 预计算的**独立纹理**，切换天空盒没重新生成它们 → 模型 IBL 采样旧 irradiance/prefilter
- **方向**：切换天空盒时应重新生成 IBL 贴图（irradiance + prefilter + BRDF LUT），或做异步重算
- **状态**：暂缓，记录待查

## 三、视锥剔除设计要点（本次）

- 方案：CPU 侧 AABB 视锥测试（8 角点 vs 6 平面），实体带世界 AABB
- 接入点：`EditorLayer::OnUpdate` 收集 Renderables 时剔除，或 `PBRModelComponent` 提供 AABB
- 注意：模型本身 AABB（`meshes[i].AABBMin/AABBMax`）可合并成实体级 AABB
- 后续扩展：分层剔除（视锥 → 遮挡）、GPU 侧剔除（间接绘制）
